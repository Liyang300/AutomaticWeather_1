# AutomaticWeather\_1

自动气象站\_毕业设计
## 环境要求

\- Qt 版本：Qt 6.8.3（MinGW 64-bit）

\- 编译器：MinGW（Qt 安装时自带即可）

\- CMake 

\- 依赖 Qt 组件：Core、Widgets、Charts、Modbus、Sql（安装 Qt 时勾选 Charts 模块），详情见Cmack.txt



\## 运行步骤

1\. 克隆仓库到本地

2\. 用 Qt Creator 打开 `CMakeLists.txt`

3\. 选择构建套件：`Desktop Qt 6.8.3 MinGW 64-bit`

4\. 点击「构建」→「运行」
